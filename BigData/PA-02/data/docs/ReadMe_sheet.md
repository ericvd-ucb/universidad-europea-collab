# Hoja «ReadMe» del libro de origen

*Copia literal (en inglés original) de todas las celdas no vacías de la hoja `ReadMe` del libro `International_airline_activity_Table1_2009toCurrent_1125.xlsx`. No se ha omitido nada de esta hoja.*

This data shows passenger, freight and mail data by airline and country of port for operations by international scheduled airlines.

The data corresponds to Table 1 data from the International Scheduled Air Transport publications.

The data is in database format rather than tabular format to make sorting and filtering easier.

Please refer to explanatory notes  - see sheet ExpNotes

**Lista de campos de la hoja (campo → descripción), tal como aparece en el origen:**

- `Month` → Month
- `Scheduled Operator` → Airline
- `Country to/from` → Country of port (uplift/discharge)
- `Passengers In` → Passengers inbound to Australia
- `Freight In` → Freight inbound to Australia in tonnes
- `Mail In` → Mail inbound to Australia in tonnes
- `Passengers Out` → Passengers outbound from Australia
- `Freight Out` → Freight outbound from Australia in tonnes
- `Mail Out` → Mail outbound from Australia in tonnes
